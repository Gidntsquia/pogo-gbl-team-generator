# ROADMAP — the why

**North star:** Jaxon feeds in a CSV of their actual Pokemon; the tool tells them the best Great League (CP ≤ 1500) teams of 3 they can field, validated by pvpoke's real battle engine running full **3v3 team battles** against the current meta — not eyeballed rankings, not hand-waved coverage scores.

**Definition of done (MVP):** `node src/cli.js their-export.csv` produces a ranked report of teams with team-battle win rates vs meta teams, best leads, and hardest matchups — end-to-end green tests, README a stranger could follow.

Sample size is small (one fixture, one topK/opponent count) — a larger multi-seed/multi-fixture run would tighten confidence, but the qualitative finding (current default is reasonable, doesn't need urgent revision) is now backed by a repeatable, checked-in tool instead of only a judgment call. - ~~**TrainingAI variance study**~~ — quantified (2026-08-21): `scripts/variance-study.mjs` + `test/varianceStudy.test.js`. First established that AI randomness itself is NOT the variance source: `src/engine/teamBattle.js` already patches the vm's `Math.random` with a seeded mulberry32 PRNG derived per battle from (teams, leads, seed), so vendor/pvpoke's own `TrainingAI.js` `Math.random()` calls (energy estimates, move-option picks, IV-combo choices, buff rolls) are fully pinned — `test/bench.test.js` already verified bit-identical results for a FIXED battle order under a fixed seed. The real, order-dependent variance source is the `resetMoves()`/`bestChargedMove` stale-`self.index` mechanism GOALS T15b/T15c found (see `src/engine/README.md`'s "Known limitation" section). This script quantifies it directly: runs the SAME real battle set (5 candidates × 8 opponents × all 9 lead pairings = 360 battles) through 4 different seeded-deterministic orderings (a full reversal + 3 shuffles) vs a canonical baseline, on real curated meta teams. **Measured result:** each alternate ordering flipped exactly 1/360 battles (0.28% flip rate, consistent across all 4 orderings — suggests one specific matchup sits right at a moveset tie-break knife-edge), max win-rate delta 1.4 percentage points, and **team RANKING never changed** across any ordering. Consistent with T15c's own by-hand finding (1 flip in a 90-battle sample) at a larger, more systematic scale. Practical takeaway: order-sensitivity is real but small and did not move which team a funnel/report would recommend in this sample — worth re-running at larger scale (more candidates/opponents, more shuffle seeds) if more confidence is wanted, but the qualitative finding (rare, bounded, rank-preserving in practice) is now backed by a repeatable, checked-in tool instead of an anecdote.
